# **Jogo Mario**  
## **Descrição**  
Projeto de um jogo inspirado em Mario desenvolvido para praticar conceitos de desenvolvimento Front-End e controle de versão utilizando Git e GitHub.  
O jogador deve controlar o personagem e pular os obstáculos para evitar colisões e aumentar sua pontuação.  
## **Objetivo**  
O objetivo do projeto é desenvolver uma aplicação Front-End simples e funcional, além de aplicar conceitos de organização de projetos, versionamento de código, branches, commits e integração utilizando Git e GitHub.  
## **Tecnologias**  
- HTML5  
- CSS3  
- JavaScript  
- Git  
- GitHub  
## **Instalação**  
Clone o repositório:  
git clone https://github.com/cacodo/jogoMario.git  
Entre no diretório do Front-End:  
cd jogoMario/frontend  
O projeto não possui dependências externas que precisam ser instaladas.  
## **Execução**  
Abra o arquivo index.html, localizado dentro do diretório frontend/, em um navegador.  
Exemplo:  
vivaldi index.html  
Também é possível abrir o arquivo diretamente utilizando outro navegador.  
## **Como jogar**  
- Pressione **Espaço** ou  **Seta para cima** para pular.  
- Também é possível clicar na tela para realizar o pulo.  
- Evite colidir com o cano.  
- A pontuação aumenta enquanto o jogador permanece na partida.  
- Após uma colisão, utilize o botão **Reiniciar** para começar novamente.
